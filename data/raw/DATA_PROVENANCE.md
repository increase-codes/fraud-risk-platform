# Dataset Provenance

## Dataset

File: `CCFraud_data.csv`

Rows: 500,000

Columns: 32

## Provenance

A 500,000-row republished copy/subset of the Bank Account Fraud (BAF)
dataset family, obtained from a third-party GitHub repository.

The exact upstream source and transformation used to produce this
500,000-row copy cannot currently be established from the GitHub
repository alone.

The dataset schema matches the BAF dataset family.

## Important note

This dataset is synthetic/privacy-preserving data derived from
an anonymized real-world bank-account fraud dataset. It should not
be described as raw real-world banking transactions.
